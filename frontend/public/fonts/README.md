# Self-hosted fonts

Downloaded from the Google Fonts source repository; no runtime font CDN requests.

- Inter variable (opsz, wght): https://github.com/google/fonts/tree/main/ofl/inter
- JetBrains Mono variable (wght): https://github.com/google/fonts/tree/main/ofl/jetbrainsmono

Original variable TTF files are retained with their SIL Open Font License texts.
The fonts include Vietnamese coverage. CSS requests Inter 400–800 and JetBrains Mono 400–700.
